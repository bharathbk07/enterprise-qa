# Community conduct

Treat contributors and users respectfully. Keep issues, reviews and discussions focused on the project and on reproducible technical evidence. Welcome questions and different levels of experience; give actionable feedback without personal attacks.

Harassment, discrimination, threats, doxxing, deliberate exposure of private data and abusive or disruptive behavior are not acceptable in project spaces. Do not post credentials, customer information or other people's private evidence in any discussion.

Maintainers may moderate project spaces using their available repository permissions, including removing inappropriate content or limiting participation. Responses should be proportionate and protect private information. No dedicated conduct-reporting inbox is currently published. If the maintainer provides a private contact channel on their GitHub profile, use that channel for sensitive conduct concerns rather than a public issue. This document does not promise confidential handling through an unspecified channel.

For software vulnerabilities, use SECURITY.md. For ordinary technical problems and feature requests, use SUPPORT.md.
