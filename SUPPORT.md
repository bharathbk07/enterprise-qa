# Support

For reproducible bugs and feature requests, use the repository's issue templates when Issues are enabled:

https://github.com/bharathbk07/enterprise-qa/issues

Search existing reports first. Include the toolkit revision, operating system, Node/Python versions, agent client/version, affected skill/agent or recorder command, expected behavior and actual behavior. Supply a minimal synthetic or redacted reproduction. Explain which documentation you followed and which checks you ran. For an MCP issue, include the product edition/deployment and connector capability information, never tokens or private tenant data.

Security-sensitive findings follow SECURITY.md and must not be posted publicly. For general setup questions, a public issue without sensitive data is appropriate when repository Issues are available. This project does not currently promise dedicated support, a response SLA, a hosted service or support for every client/edition combination. Do not assume GitHub Discussions or paid support is configured.

Current verified behavior and open limitations are recorded in verification.md and docs/GAP-REVIEW.md. Please distinguish verified results, suspected causes and proposed improvements in reports.
