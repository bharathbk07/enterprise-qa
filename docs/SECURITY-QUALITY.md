# Security verification for the selected application

Reference checked 17 October 2026: [OWASP ASVS project and versioned requirements](https://owasp.org/projects/asvs). ASVS 5.0.0 is the verified reference version for this package; select a project-appropriate scope/level and use exact versioned requirement IDs. Verify the actual criterion before citing it; this toolkit does not bundle the standard or certify compliance. An OWASP Top 10 scan alone is not complete security verification.

Start with a bounded threat model: actors, assets/data, entry points, trust/tenant boundaries and abuse paths. Map the selected frontend/API/service/storage/dependency controls to implemented evidence. Prioritize authorization and tenant isolation, authentication/session lifecycle, unsafe input/output, sensitive data, secrets/configuration, dependency provenance and third-party failure/security boundaries. Inspect framework defaults and actual application overrides rather than assuming a product name guarantees a control.

Separate static review, dependency alerts, configuration evidence, passive observation and authorized active reproduction. Inspect installed scanner/version/output semantics before selecting it. CVE/dependency presence is a candidate finding until applicability/exposure is assessed. Never invent a CVSS score, copy payloads to unrelated services, log credentials or fetch customer records to demonstrate impact. Produce a minimal safe reproduction with synthetic data and bounded target scope. Preserve redacted evidence and candidate alternate explanations.

A proposed fix should address the control/mechanism and include a negative regression proving the original abuse path is rejected plus legitimate access still works. Escaping, authorization, validation and encryption choices depend on the actual context; do not prescribe a generic sanitizer or broad permission grant. Application/production changes remain within the shared approval workflow. Formal RCA and release/compliance conclusions require their own evidence; scanner pass is not certification.
