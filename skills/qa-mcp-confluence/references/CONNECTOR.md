# Confluence connector

One Rovo MCP connection serves the separate Jira and Confluence specialists. This official endpoint is for Atlassian Cloud; do not claim Data Center support. Use OAuth and existing site/project/space permissions. Discover actual tools on demand.

Source: [official setup](https://developer.atlassian.com/cloud/rovo-mcp/). Documentation verified 15 October 2026; no live tenant validation performed.

Use the shared engineering contract for scope, bounded reads, approval, redaction and error handling. Templates under `.qa-agent/integrations/templates/` are manual-merge drafts; they do not connect or install a server. Current client/version/edition and actual tools must be checked during setup.
